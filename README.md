### 👨‍💻 System Log: The Developer

I am a B.Tech CS student who loves blending logic with creativity. I don't just want code to run; I want it to look beautiful and feel intuitive. Currently, I'm navigating the vast worlds of User Interfaces (UI) and Machine Learning, picking up new skills one bug at a time!

- 🚀 **Mission Control:** Currently architecting **AAPDA-MITRA** (an AI-powered flood prediction dashboard), refining **ResuSmart** (an ATS-friendly resume builder), and adding cool features to a custom **Voice Assistant**.
- 🧠 **The AI Lab:** Exploring the foundations of AI/ML, Python automation, and experimenting heavily with **Prompt Engineering** *(I try, I learn, and sometimes the AI actually listens to me!)*.
- ⚡ **Superpower:** Taking complex data and turning it into sleek, interactive UI designs.
- 🎬 **Offline Mode:** When I'm stepping away from the keyboard, I'm probably watching a gritty cop mystery, a real-story military film, or finding inspiration in the classic movie *Anand*.
